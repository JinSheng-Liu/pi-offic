# 前端工作台重构与验收

## 审查和方向

原界面混用蓝色和绿色、样式重复覆盖、主页面承载全部业务逻辑和界面、移动端三栏堆叠、聊天直接显示 Markdown 源文本。保留文档大纲、原生编辑器、助手与历史三栏信息架构；以蓝白工作台为主，低动效，统一间距、圆角和状态颜色。design-taste-frontend 的展示站点规则仅用于适用的审查和可访问性部分，不将编辑器改造成展示网站。

## 代码边界

- App.vue：工作台布局、面板组合、主题与窄屏面板状态。
- composables/useStudioWorkspace.ts：当前文档、保存关闭、模型设置、流式任务和后端调用。仍是单一工作区协调模块，不宣称已经拆成多个独立业务领域。
- types.ts：共享前端契约。
- components/ChatMessages.vue：Markdown、安全文本渲染、执行步骤、跟随底部滚动。
- components/VersionHistory.vue：版本记录和验证范围展示。
- components/WorkspaceDialog.vue：复用浏览器 dialog，焦点约束与 Esc 关闭。
- DocumentOutline.vue：原有编辑器原生大纲与只读规则补充，不改变文件。
- style.css：统一语义色彩变量、浅深色主题和四档布局规则，替换历史追加覆盖样式。

未迁移 Vue 框架，未自研 DOCX 编辑器、Markdown 解析器或弹窗引擎。新依赖 markdown-it 禁用原始 HTML，默认过滤危险链接。文档页面保持作者原始颜色，主题只改变宿主工作台。

## 实际验证

- TypeScript 与生产构建通过。
- check:api 通过，覆盖真实 Pi 适配器的模拟分段输出、工具调用、取消与断开流程。
- node --test test/outline.test.mjs：2 项通过。
- 浏览器打开研究报告无格式文档，产生 16 个规则大纲项。
- 1920、1440、1024、390 宽度无页面横向溢出，顶部为单行（桌面 64px，窄屏 60px）。
- 窄屏大纲与助手切换保留输入草稿。
- 模型设置和页面设置对话框打开、Esc 关闭通过；版本历史标签显示正常。
- 独立文档通过编辑器公开命令修改标题，取消关闭保留修改，保存生成 v2，再关闭成功。
- scripts/browser-frontend-check.cjs 模拟 SSE 验证标题、加粗、列表、工具步骤渲染，script 文本不生成脚本节点。此测试不是实际模型调用。
- 浅色、深色、文档视图、聊天视图、窄屏截图位于 data/validation/frontend-*.png，已实际查看主要截图。

初次模拟 SSE 的命令行转义错误造成缺少完成事件，改用独立脚本后通过。安装期间 npm 提示 esbuild 安装脚本被阻止，没有绕过；实际构建成功。

## 已知限制

仍有编辑器大包构建警告。没有运行 Lighthouse 或声明 Core Web Vitals 达标。主题对比度检查针对宿主语义色，非 DOCX 用户内容。编辑器内部部分英文和字体缺失提示来自原生组件，本轮未修改依赖源码。当前大纲活动章节仍依赖编辑器渲染标记，升级时需专项回归。用户业务文档不因改版而自动规范格式。
