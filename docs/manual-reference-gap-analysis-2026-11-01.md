# 系统排版与人工参考对比分析

## 分析范围与结论

对比 C:/Users/Administrator/Desktop/replayed.docx 和 E:/浏览器下载/基于Spring Boot 的校园二手交易平台的设计与实现.docx。只读分析原件；以人工文件作为本次参考，不把其所有细节当作通用论文规范。

结论：系统输出保留了内容，但没有达到参考文档的排版效果。问题跨越封面分区、图片段落、表格单元格、目录样式以及分页策略，不能归为提示词不够详细。此前成功重放16项操作只能证明工具完成了那16项操作，不能证明操作覆盖了完整排版需求。

## 已确认的差异

### 封面与前置部分

Word 字号 sz 以半磅计。参考文件“本科毕业论文（设计）”为90（45磅），系统为24（12磅）；学生信息等封面字段参考为36（18磅），系统为24（12磅）；题目两行参考18磅，系统22磅。参考封面信息多处使用2.5倍行距（600/auto），系统使用1.5倍（360/auto）。ABSTRACT参考16磅且居中，系统12磅且未恢复居中。

这些不是统一字体的小误差，是没有落实封面/前置部分独立规则。封面应按参考或已确认模板处理，不纳入普通正文批量操作。

### 图片

两份文档均有89处inline和116处anchor绘图节点。89处嵌入式图片中，人工版86处所在段落有直接居中，系统0处。图像文件保留不能代表图像排版完成。

浮动图片须另行检查定位参照、偏移、环绕和锚点；不能仅修改段落jc就承诺图片居中。不能把复杂图形转为嵌入式作为无条件默认。

### 表格

均为23表、650单元格；474个单元格的段落对齐设置不同。第一张表的“字段名、类型、约束、注释”及id/int等单元格，参考为居中，系统未恢复对应对齐。

该统计比较直接属性及普通段落样式继承，不包含完整表格条件样式计算，不能等同于474个已渲染错误单元格。第一表tblPr的序列化不同主要是属性顺序，不能据此宣称表宽变化。

需要区分表头、标识/数值短列和说明长列，水平对齐与垂直对齐分别验收，不能用全文正文规则覆盖所有单元格。

### 目录

两份文件都保留TOC和PAGEREF字段，域指令一致。参考目录条目使用TOC1/TOC2，右对齐制表位8296 twips并带dot引导；系统目录缺少这些段落样式和制表位。

之前将目录笼统描述为静态目录不准确。当前主要问题是目录排版未恢复，且正文重新排版后没有证明缓存页码已重算。应先规范标题，再恢复目录样式/点引导，完成分页后由支持域更新的引擎刷新并验收页码。

### 空段、行距与分页

两份文件均保留130个正文顶层空段。系统对空段也写入了新的行距等格式，原有占位结构在新字号行距下可能产生不同高度。

系统增加75处keepNext=true和75处keepLines=true，另有144处keepLines=false；参考未显式设置这些节点。不能因数量增加便判断每一处错误，但必须检查标题绑定范围与连续同页链是否过长。

130个空段本身不等于130处错误；参考也使用空段。应区分封面有意留白、分节承载段、图形锚定段和无意义空段。不得无条件删除所有空段。

两者仍保留61个lastRenderedPageBreak节点，这是旧渲染痕迹，不能据此报告当前页数。未完成实际页面渲染，因此没有量化“空白页比例”或具体页面缺陷。

## 产品根因

1. 操作规划以字体/段落范围为中心，缺少封面、目录、图表、题注等文档区域的语义计划。
2. 正文全局格式覆盖了本应独立处理的区域，同时遗漏了图片段落居中、单元格列角色等关键细节。
3. 工具校验针对已请求属性，没有需求覆盖清单；模型漏掉一类任务仍可能得到validation passed。
4. 没有布局渲染—检查—修正闭环；内容无损和属性重读不能证明页面合格。
5. 无格式输入不能凭空还原所有原始设计。用户提供参考时应提取并确认参考规则；没有参考时应使用明确模板，而不是让模型临时猜测。

## 建议的改造次序

P0：建立分区计划与覆盖清单。操作前列明封面、声明、摘要、正文、目录、图表、参考文献；对未处理/不支持部分明确失败或部分完成。封面禁止误套正文规则。

P0：把本次两份文件作为固定验收对，建立可执行断言：封面关键字号、ABSTRACT居中、86处参考inline居中、参考单元格对齐、TOC层级与点引导。指标采用参考适用范围，不机械要求整个XML相同。

P1：扩充现有docx4j适配器调用能力，提供图像段落、表格行列单元格和目录样式操作；缺口用少量OOXML补充。无需另写DOCX引擎。

P1：增加布局验证。优先复用现有编辑器公开布局能力检查明显溢出/孤立标题；最终使用已确认的DOCX渲染环境检验分页和目录页码。不同渲染器的结果不得混为Word兼容结论。

P2：按分区批处理与按需读取结构，控制输入体积；补充字体可用性检测及替代提示。
