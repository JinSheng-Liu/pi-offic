# 学术论文

## 适用范围

- 适用于用户要求整理的论文、学位论文或学术文章。
- 识别线索是论文标题、摘要、章节等组合，不是单个“参考文献”。
- 学校、期刊及用户参考样式优先；参考封面已上传且文字相同时优先restore_reference_cover（真实referenceId/referenceRevision），保留横线、字号及不同信息行布局，不用通用两列替代；文字不同时需字段映射。
- 不存在通用的论文字号组合，不默认采用 APA 或某所学校规范。
- 用户只改正文时，不扩大为封面、目录和参考文献重排。
- 混合文档中的合同、代码、表格按相应区域单独处理。
- 公共字体和版本规则由 docx-formatting 提供。
- 图表、目录任务分别按需加载 docx-objects、docx-toc-sections。

## 输入与前置检查

- 读取用户指定的适用学校、模板版本和目标区域。
- 用 inspect_document 分页读取相关结构，不能把首批段落当全文。
- 记录封面、授权书、声明、摘要和正文边界；用户要求参考授权书时用restore_reference_authorization，仅文字及符号一致才恢复，保留目标分节，分别验收，封面完成不代表授权书完成。
- 区分摘要标题、摘要正文、关键词标签和关键词内容。
- 查明 ABSTRACT 是独立标题，还是正文中的普通词。
- 检查目录条目是否有独立样式，不能仅按章节文字判断。
- 记录参考文献编号、列表和悬挂缩进，不假设都是普通段落。
- 缺少模板数值时保留原有设置，必要时只询问影响执行的要求。

## 识别与决策

- 封面与正文首章前的题名、作者分别建立范围；正文题名不是章节Heading，按要求独立设置字号、居中和段距，保留原文，不套普通正文规则。
- 封面不能继承正文的字号、首行缩进和固定行距。
- 中英文摘要采用各自明确指定的字体，不混同中文和西文字体槽。
- 独立章节标题与段内小标题分开，后者不将全段设为 Heading。
- 参考文献的编号与悬挂缩进不可被正文首行缩进覆盖。
- 图题、表题与正文分开，不因同为 Normal 样式而一起处理。
- 不凭空白段数量判断封面或章节间空白多余。
- 不同章的同级标题应比较同一组属性，而非只比较字号。

## 执行流程

- 用户指定参考整篇排版时，先调用audit_reference_front_matter逐区列出差异，完成后重查；缺失或未匹配区域明确报告，不用封面完成代替全部前置页完成。
- 对已确认区域使用 apply_formatting 的明确 indices。
- 用户授权封面重排时，普通连续题名/信息段可独立用coverLayout、indices、cover.widthPt/labelWidthPt生成无边框两列；总宽须适配页面，清理定位空白并合并题名续段，完成后重读全部索引，复杂结构拒绝。
- 按用户要求为明确独立标题设置 Heading 层级及字体。
- 正文统一字体和行距时排除图片段落、表内文字与引用块。
- 参考文献只设置已要求的属性，保留编号与引用文字。
- 题注插入会改变索引，插入后重新读取结构再执行后续格式。
- 原创性声明使用restore_reference_declaration，要求原文和符号一致；每次提交保留revision并重新检查参考差异，不以属性匹配声称页面验收通过。

## 验收要求

- 封面除字号段距还须检查layoutRisks中的COVER_SPACE_ALIGNMENT/COVER_SPLIT_TITLE：空格定位和独立居中续行未修复时不得报告完成；信息栏应按模板用统一制表位或无边框表，禁止用空格补齐。
- 分别检查中文摘要标题与 ABSTRACT 的对齐、字体和字号。
- 对所有目标正文回读，不以一个示例代表整篇。
- 检查目标标题文本与层级，确认未把目录条目提升为标题。
- 核对参考文献首行和悬挂缩进没有被正文规则覆盖。
- 图表结果按对象技能验收，不用文字段落验收代替。
- 目录域保存完好不代表页码已更新，页码重算另列未支持。
- 无页面渲染证据时，封面占页、空白和跨页状态列为待视觉确认。

## 案例与失败边界

- 案例：用户要求正文小四，封面原为大字号，应保留封面。
- 案例：要求英文 Times New Roman，回读西文字体槽而非只看中文字体。
- 案例：ABSTRACT 为独立标题，不能按其后一段摘要正文处理。
- 反例：看到“一、”就把与正文混排的整段改为一级标题。
- 反例：为压缩页数将所有字体缩小或删除全部空段。
- 反例：把样稿中的学校、作者和日期复制到目标内容。
- 规范冲突影响字号或范围时，指出冲突后澄清，不默默取平均。
- 完成报告逐项区分格式已验证、未支持和待页面确认。
