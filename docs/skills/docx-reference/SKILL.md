# 参考样稿

## 适用范围

- 适用于用户要求参照样稿或已提供规范调整当前文档。
- 参考只提供格式依据，不提供目标文档替换内容。
- 样稿必须实际可读，不能仅凭路径或文件名声称已分析。
- 当前文档工具不能读取任意本地参考文件路径。
- 工具无法读取参考时，可使用用户明确提供的格式要求。
- 没有可靠参考数据时，不执行声称“完全照样稿”的修改。
- 区域执行规则由相应类型技能补充。
- 图表与分节分别按需加载对应对象技能。

## 输入与前置检查

- 先确认用户想匹配哪些区域和哪些属性。
- 区分用户硬性数值与“类似样稿”的风格偏好。
- 检查可用参考是文本说明、属性记录还是实际可读取的结构。
- 记录参考规范版本、适用对象和证据来源。
- 分页读取目标文档，定位与参考对应的区域。
- 比较封面、摘要、正文、目录、图表、附录是否都有对应关系。
- 相同段落序号或相同标题文字不等于相同角色。
- 缺少的关键区域属性明确列出，不凭视觉印象编造数值。

## 识别与决策

- 用户明确要求优先于样稿中的不一致设置。
- 按区域角色匹配，不做整篇样式覆盖。
- 封面题名与作者信息分别匹配，不能只匹配一个大标题。
- 摘要标题、摘要正文与关键词分开建立规则。
- 正文、参考文献、列表不能共享一个缩进模板。
- 表格既看表头也看数据与说明列，不把参考整表居中照搬。
- 嵌入图段落对齐不能替代浮动图相对页面定位。
- 参考中的偶发手工错误不能在没有说明时当作强制标准传播。

## 执行流程

- 先建立参考区域、目标区域、属性差异和执行能力清单。
- 对已确认差异使用明确 indices 处理，不猜范围。
- 只复制可验证的格式值，不复制文字、签名、日期和组织名称。
- 分节尺寸与边距独立于段落字体和行距操作。
- 中西文分别指定字体，不能只照抄参考 font.name。
- 图片段落、题注与单元格按对象技能定点处理。
- 无法支持的目录制表位、浮动定位等留在未完成清单。
- 每批成功后回读，确认目标值真正落到对应区域。

## 验收要求

- 将输出逐项与可用参考属性对比，而非只看操作返回成功。
- 封面题名与信息行分别核对字号、对齐和行距。
- 检查正文首行缩进与参考的悬挂或制表布局是否混淆。
- 对比固定行距与倍数行距的规则，不仅比较数字。
- 核对表格特殊单元格和图片段落的实际目标属性。
- 验证目标内容仍为用户原文，未被参考样稿内容替换。
- 结构一致不等于页面一致，未渲染时不承诺逐页复刻。
- 结果列出已匹配、部分匹配、缺少依据和当前未支持项。

## 案例与失败边界

- 案例：参考封面题名 30pt、信息行 18pt，两组分别执行。
- 案例：参考正文相同但图像布局不同，不能宣称整体一致。
- 案例：用户只提供正文格式数值，先完成正文并说明其他区域无依据。
- 反例：第十段对第十段复制格式，忽略两份文档内容长度不同。
- 反例：把样稿学校、作者和日期复制到用户文档。
- 反例：参考文件不可读却输出“已逐页比对完成”。
- 遇到参考规范和用户要求冲突，指出具体属性并确定优先级。
- 没有本轮实际证据的旧分析结论，不能直接当成当前文档验收结果。
