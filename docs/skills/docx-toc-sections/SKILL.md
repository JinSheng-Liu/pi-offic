# 目录与分节

## 适用范围

- 适用于目录条目格式、分节页面设置和分页边界检查。
- 目录文本、目录域和标题大纲不是同一结构。
- 不通过新增静态目录替代用户的原生目录域。
- 分节页面参数与普通段落参数分别处理。
- AI通过update_native_toc调用当前编辑器原生目录；需要页面保持连接，完成正文排版后执行。
- 用户仅改边距时不调整章节标题或正文缩进。
- 字体和段落设置的通用规则沿用公共技能。
- 不得引入用户已排除的 LibreOffice 或 PDF 转换作为替代流程。

## 输入与前置检查

- 读取 sections，记录真实节索引和现有页面参数。
- 读取目录附近段落，区分目录标题与条目。
- 必须核对真实TOC域；TOC样式或章节文字列表都不能单独证明存在原生目录。
- fields 数量只是文档字段统计，不能证明每段都属于目录。
- 不能可靠确定目录边界时先明确范围，不按关键词猜全部条目。
- 记录原有分节、页眉页脚引用和页面方向。
- 检查 pageBreakBefore、keepNext、keepLines 等段落分页属性。
- 空段、空页与分节段不能仅凭空文本互相推断。

## 识别与决策

- 目录条目不能设置 Heading，否则可能污染大纲和目录来源。
- 目录标题与TOC域共处内容控件首段而拆页时，可单独提交scope=tocTitle、indices，将标题移到控件前，保留原域。
- 字体、缩进可以按明确条目索引处理，但不能冒称更新目录页码。
- 点引导符和右对齐页码通常依赖制表位，不用手打点线替代。
- 分节页面尺寸与边距单位为 twips，不是 pt。
- 用户仅改一个节时，不对所有节统一纸张与方向。
- 横向页面和特殊页边距可能服务宽表格，应保留未指定项。
- lastRenderedPageBreak 是缓存，不能用作实际页数验收。

## 执行流程

- 正式目录用update_native_toc：refresh更新已有TOC；replace替换连续手工条目indices（不含标题）；insert在paragraphIndex之前插入。
- 替换条目必须与正文标题对应；失败不能退回普通文字排版并声称目录完成。保存后重新读取索引。
- 使用 scope=sections 与已读 sectionIndices 构建页面操作。
- page 与 margins 可同一操作设置，不加入 font 或 paragraph。
- 目录条目字体用独立段落操作；无已有制表位且单Tab后为页码时，可用tocPageTabPosition设置右对齐点引导位（pt）。
- 只修改明确要求的宽高、方向或边距属性。
- 标题分离后必须重读索引；制表位不得超出实际文字区域，页面变更后回读sections。
- 章节分页需求通过具体段落属性处理，不批量插入空段。
- 明确误设的 keepNext 等属性可定点修改，不能全篇清零。
- 已有独立PAGE页码可单独提交footerPageNumber、sectionIndices、alignment和font{name,size}；共享页脚需覆盖全部引用分节，不新增页码或改编号。

- 用户明确要求全文底端居中阿拉伯页码时，ensurePageNumbers独立提交；保留起始编号，空白页脚补PAGE，复杂页脚拒绝。

## 验收要求

- 核对目标节纸张宽高、方向与边距数值。
- 确认未指定节的页面参数仍保持原值。
- 检查目录条目字体与段落属性符合请求。
- 确认没有将目录条目变成正文标题层级。
- 目录域及页眉页脚引用保真以工具检查结果为依据。
- 页码重算没有运行时，明确说明页码仍待支持工具更新。
- 分节位置、空白页和横向页实际效果需页面查看。
- 区分页面属性已落实、目录内容已保留与视觉分页已验证。

## 案例与失败边界

- 案例：仅第二节横向，使用真实第二节索引而非全部 sections。
- 案例：目录标题要求居中，不能同时居中所有目录条目。
- 案例：设置上下边距，保留未要求的装订线与其他边距。
- 反例：通过删除所有空段清理所谓空白页。
- 反例：手工添加点字符，声称实现目录右对齐引导符。
- 反例：保存 DOCX 后直接宣称目录页码已重新计算。
- 看到未开放的版式要求，说明具体缺口并继续其他明确可执行项。
- 最终结果按节和目录区域报告，不把包校验当分页验收。
