# 段落与字体

## 适用范围

- 作为所有格式任务的公共技能常驻加载。
- 仅通过提供的工具读取和修改当前 DOCX。
- 用户明确要求优先，其次为用户提供且适用的规范。
- 特殊区域保留规则优先于未经确认的类型默认建议。
- 只更改请求涉及的属性，不顺便重写内容。
- 类型任务由相应技能补充，本技能不提供统一数值模板。
- 复杂图表与分节由专门技能处理。
- 不能把格式修改成功等同于页面布局已合格。

## 输入与前置检查

- 先调用 inspect_document，记录当前 revision。
- 先用默认精简结构扫描分区，再用 indices 定点读取完整格式；不反复扫描全篇详细属性。
- 发现 nextOffset 时继续读取尚需处理的部分。
- summary 没有全文段落，不能据此直接执行整篇格式。
- 检查 textTruncated，截断文本不能用于推断完整局部匹配。
- 定点读取字体槽、样式、lineSpacing 规则、tabStops 制表位、前导空白和编号。
- 检查目标是否包含图片、表内文字、目录、封面或签署区。
- 用户范围不明确且影响修改对象时先澄清，不猜测。

## 识别与决策

- Normal 样式不等于正文，unclassified-text 也不是确认正文。
- body 只排除已识别特殊对象，复杂文档优先明确 indices。
- all 只用于用户确实要求同一属性覆盖全部可处理段落时。
- 同一范围的不同属性可合并，互相冲突的设置先解决冲突。
- font.name 配合 latinName 表达中文与西文分别指定字体。
- 用户写 Time New Roman 时使用实际字体名称 Times New Roman。
- 字体指定不代表本机已安装，实际渲染回退另行确认。
- 不通过字号、颜色或编号外观自动判定全部标题层级。

## 执行流程

- apply_formatting 必须携带读取所得 revision 和准确范围。
- 整段角色优先scope=namedStyle：指定indices、styleName、font/paragraph；每步独立，可纳入格式计划。
- 独立章节明确outlineLevel，非章节设10；局部强调用scope=text；用户明确原生标题样式时可设Heading1–Heading9。
- 命名样式写入真实定义并关联段落；只清理指定属性，保留其他强调，不全局覆盖已有样式。
- scope=text 使用一个段落索引、准确原文，重复文字指定 occurrence。
- 段落单位为 pt，缩进与间距不得混用字符数或 twips。
- 用户要求两字符缩进时，先确认字号和适用段落再换算数值。
- 单个前导Tab且无既有制表位/缩进/编号的普通段落，可用leadingTabPosition设置文字起点；不等同首行缩进属性。
- lineSpacing 是固定 pt，lineSpacingMultiple 是倍数，两者互斥。
- 标题可与下段同页，不能给全部正文开启 keepNext 或 keepLines。

- 全文多步骤请求优先execute_format_plan：一次声明完整的小批次清单，按章或对象提交并推送预览；结构转换须单独执行后重读。
- 计划audit只验收声明目标；failures和unsupported必须报告，不能代表自然语言要求无遗漏。

- 段内标题使用scope=characterStyle、styleName、单段indices、准确text和font；保留正文段落样式，不改变大纲层级。

## 验收要求

- 回读styleName和font.effectiveFonts；直接格式为空可能来自样式继承，不等于字体未设置。
- font.name 不代表所有中文最终字体，null 可能来自样式继承。
- 核对字号、对齐、首行缩进、段前后距和行距规则。
- 有前导 Tab 时，数值正确不代表实际文字起点已经正确。
- 确认标题层级没有误作用于目录条目或混排整段正文。
- 检查邻近未指定区域，避免把局部请求扩大为全段或全文。
- validate_document 的包检查不能代替本次属性逐项回读。
- 最终标记已验证属性、未完成要求和待视觉确认项目。

## 案例与失败边界

- 案例：中文宋体、西文 Times New Roman，分别验证字体槽。
- 案例：正文两字符缩进，封面与图注不跟随正文范围。
- 案例：段内“工作目标”需黑体，仅设置匹配文字。
- 反例：把固定行距设为 0 表示单倍行距。
- 反例：通过缩小字体消除大面积空白而违背用户字号要求。
- INVALID_FORMAT_ARGUMENTS 且未提交、可重试时按 correction 修正一次。
- 版本冲突或结构保护失败必须停止，不能换版本盲目重试。
- 已提交操作不重复执行，后续失败按真实已提交状态报告。
