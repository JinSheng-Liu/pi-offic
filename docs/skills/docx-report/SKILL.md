# 工作与研究报告

## 适用范围

- 适用于工作报告、研究报告、调研报告和工作总结。
- 短汇报与长研究报告分别判断，不共用固定封面与目录要求。
- 识别依据为标题、章节与内容用途，不只看文件名。
- 用户提供的企业模板、品牌规范和明确要求优先。
- 未要求时不增加摘要、结论、目录或其他新文字。
- 报告中的合同附件、技术代码和表格保留各自规则。
- 公共段落操作沿用 docx-formatting。
- 涉及数据表、图表和题注时加载 docx-objects。

## 输入与前置检查

- 读取用户要求的阅读场景和需要整理的区域。
- 分页查看封面、信息块、摘要、正文、结论和附录。
- 确认现有标题层级与同级标题的实际格式。
- 区分正文叙述、列表、引用和关键指标独立段。
- 检查图形段落和题注是否被混入普通正文。
- 读取表格与 cells，定位表头、数值、单位和说明列。
- 记录用户已指定的字体、字号、行距和边距。
- 无法确认品牌色或模板时，保留现有颜色而非自行添加。

## 识别与决策

- 通过层级、间距和对齐建立阅读顺序，不用多种装饰字体堆叠。
- 标题层级应来自明确结构，不凭字号大小反推全部语义。
- 封面与摘要信息块不能套正文首行缩进。
- 结论中的列表保持列表缩进，不强制改成普通段落。
- 数据列、单位列与长说明列允许不同对齐方式。
- 图注、来源说明与报告正文分开设置。
- 不能通过缩小字体、强行压行距来填补或消除页面空白。
- 用户只指定某一属性时，其他排版属性尽量保持。

## 执行流程

- 先按区域列出要统一的属性与保留项。
- 使用明确 indices 处理报告正文与摘要正文。
- 标题按层级分组操作，避免全标题只剩一种视觉层级。
- 对关键指标只执行用户要求的强调，不改写数字或单位。
- 对表头和表体分别读取、选取和设置水平对齐。
- 图片段落单独处理，防止固定小行距压缩图形显示。
- 需要目录或页面边距时按需加载 docx-toc-sections。
- 提交成功后回读目标，避免以重复提交代替验证。

## 验收要求

- 比较同级标题的字体、字号、段前后距和分页属性。
- 核对摘要与正文的缩进、行距是否符合各自要求。
- 检查列表编号与层级没有被统一正文操作破坏。
- 核对数字、单位和备注文字完全保留。
- 验证表格目标单元格，保留未指定列的对齐。
- 确认图片数量、题注文字和处理范围一致。
- 留白是否均衡和图表是否跨页需要页面证据，标明待确认。
- 只对已回读的属性报告完成，不声称报告整体视觉已验收。

## 案例与失败边界

- 案例：摘要需要无首行缩进，正文需缩进，两者应分组处理。
- 案例：数字列要求居中，说明列保留左对齐，不应全表居中。
- 案例：一页工作简报没有目录，不因为“报告”类型自动补目录。
- 反例：将封面大标题改成与正文相同字号。
- 反例：为显得专业擅自加入品牌色、徽标和新结论。
- 反例：把所有段落 keepNext 开启导致大片跨页空白。
- 已有规范相互矛盾时说明具体属性冲突，不主观选择一种风格。
- 模板数字未指定时，将建议与实际执行结果分开。
