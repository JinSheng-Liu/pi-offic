# 技术方案与操作手册

## 适用范围

- 适用于技术方案、操作手册、接口说明和使用指南。
- 依据内容角色识别，不把所有包含代码的文档都当技术手册。
- 用户或组织模板优先于通用技术写作建议。
- 本技能处理既有内容格式，不改写步骤、命令和接口定义。
- 论文中的代码附录可局部使用，不替换整篇论文规则。
- 用户只改字体时不自动重组章节。
- 字体和段落的通用操作沿用公共技能。
- 涉及截图、参数表与题注时加载 docx-objects。

## 输入与前置检查

- 分页读取目录结构和需处理的章节。
- 区分概念说明、操作步骤、代码、命令与输出示例。
- 识别警示、注意、前置条件和参数解释块。
- 检查步骤是自动列表还是手动数字文本。
- 记录代码中的缩进、Tab、空格和手动换行。
- 读取 cells 以区分参数名、类型、默认值和说明列。
- 查明截图所在段落与文字说明是否为同一段。
- 缺少独立代码样式时不能单靠英文或等宽外观猜测。

## 识别与决策

- 标题层级用于导航，不能通过改写标题文字实现层级统一。
- 英文标题大小写建议不适用于自动重写中文标题。
- 步骤编号表达执行顺序，保持编号和列表关系。
- 代码缩进是内容的一部分，不能按正文缩进清理。
- 命令与输出可能混排，保留空格和换行。
- 警示块可按明确要求强调，不擅自新增警告内容。
- 参数名和说明列可采用不同字体与对齐。
- 截图段落不能套固定小行距，也不能从段落对齐推断浮动位置。

## 执行流程

- 先把正文、步骤、代码、警示和图表划为独立目标组。
- 对说明正文应用已确定的字号、行距和缩进。
- 标题使用已确认层级，不把步骤项目提升为章节。
- 代码仅修改用户要求的字体属性，保留原有内容与布局。
- 局部命令强调使用 scope=text，重复命令需准确 occurrence。
- 参数表按 cells 的 paragraphIndices 处理目标列。
- 截图与题注分别操作，插入题注后重新读取索引。
- 包含复杂域的局部文本操作若被拒绝，报告限制而非改整段替代。

## 验收要求

- 回读正文、步骤和代码的字体与段落属性。
- 检查代码、命令、输出中的文本及空白保持不变。
- 核对步骤编号顺序和缩进没有被正文规范覆盖。
- 检查同级标题格式一致，层级没有越级误设。
- 验证参数表指定列，确认默认值、类型和单位未改写。
- 检查截图数量与题注对应关系。
- 命令是否可执行不属于纯格式验收，不擅自运行文档中的命令。
- 页面跨页、截图清晰度和警示块视觉效果需要额外确认。

## 案例与失败边界

- 案例：正文用比例字体，代码保持等宽字体，分别指定范围。
- 案例：参数说明较长，应保留与短数值列不同的对齐。
- 案例：只加粗命令名时准确选取文本，不改命令参数。
- 反例：为了美观删除代码前导空格。
- 反例：将“1. 安装”步骤自动设为一级标题。
- 反例：将 Google 网页表格不合并建议用于拆解现有 Word 表格。
- Google 标题与表格指南仅支持层级和可读性原则，来源见目录 README。
- 未验证软件版本或内容正确性时，不把格式完成说成技术审核通过。
