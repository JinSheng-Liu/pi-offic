# 文档关闭与取消操作验收

2026-11-01，本地 5173，独立 outline-native.docx 测试副本。

- 已保存文档关闭后卸载编辑器，显示空工作区；刷新页面仍保持关闭。
- 有未保存修改时显示原生 dialog：保存并关闭、不保存并关闭、取消关闭。
- 取消关闭保留编辑器；不保存关闭后从最近文档重新打开，恢复保存前文字。
- 浏览器拦截 PUT 保存请求模拟 HTTP 500，验证错误显示且文档和关闭对话框仍保留；解除拦截重试，成功保存并关闭，重新打开可读到新标题。
- 放弃修改使用原生确认框，确认后重载最近保存版本。测试脚本等待保存版本标题重新出现，再关闭文档；最终空工作区已确认。额外确认命令遇到已处理弹窗，未产生额外数据操作。
- AI 停止入口复用已有 cancel 接口，运行期间禁用关闭，防止回复写回已关闭工作区。此次未运行真实 AI 中止场景。
- 类型检查与生产构建通过，仍有既有大资源包警告。

关闭不删除服务器文档或历史版本。刷新保持关闭使用当前浏览器会话 sessionStorage；重新打开文档清除此标记。手动编辑的撤销仍使用编辑器原生撤销功能。
