# 文档质量优化记录（2026-11-02）

## 已实现

- 手工题注可通过 convertCaptions 转成 Word SEQ 域，保留现有编号文字与格式。仅接受完整、连续的同类编号组；复杂结构和同名序列冲突拒绝提交。
- 检查拆分 instrText 和 fldSimple 中的已有编号序列，避免生成相互干扰的同名域。
- 转换后回读编号域；还原目标段落后比较正文结构，保护非目标内容。
- 每轮模型任务保存任务结果及本轮提交版本；失败后再次请求会提醒读取当前版本，避免重复已提交操作。
- 结构读取按实际文件内容哈希缓存；文件变化重新解析，解析失败不缓存。
- 版本保存操作记录，包括输入版本、操作列表和批次检查。操作检查不等于全部用户需求已满足。
